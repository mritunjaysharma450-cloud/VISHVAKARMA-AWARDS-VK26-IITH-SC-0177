# Image Sources

- Submitted deck concept / architecture / before-after images:
  marked AI GENERATED in the deck. They are concept illustrations,
  not evidence, and are not presented here as real diagrams or photos.
- Repo diagrams: real KiCad schematic exports (PDF, from .kicad_sch
  source files) and real SVG system diagrams, not AI images presented
  as real diagrams.
- Lab photos: real phone photos supplied by the team, described in
  Maker Journey. Photo files are uploaded separately from text pushes,
  as the text push tool cannot carry image files. Captions state what
  each photo shows and what it does not show, including that no joint
  mentor photo is in the current set.
- No AI-generated image is presented in this repo as a real diagram,
  lab photo, test result, or CAD render.
