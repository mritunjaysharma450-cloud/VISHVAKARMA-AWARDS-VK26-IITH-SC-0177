# Project Overview

Title: V-ORRA Intelligent Vehicle Signalling & Connected Road Safety System
Application ID: VK26-IITH-SC-0177
Competition: Vishwakarma Awards 2026-27, Maker Bhavan Foundation
Track: Sustainable Cities / Smart Urban Infrastructure & Asset Tracking
Team: ITM University Gwalior
Faculty mentor: Ashish Singh Chandel, Professor of Practice, SOET, ITM University Gwalior

Core innovation, in one line: a roadside pole unit that classifies which
carriageway an equipped vehicle is on, using radar tracking bound to a UWB
session, and signals that vehicle to follow No Horn Zone and Low Beam Zone
rules, with driver override always available.

Stage 2 submission was a Design Specification presentation only. This repo
contains the technical content behind that presentation, in the order of
the institution's template sections. Nothing here is presented as a
finished, tested product, and nothing is presented as a measured road result.
